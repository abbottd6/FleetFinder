Confirm Discord Account Link Removal
Confirm that you would like to remove the link to your Discord account..
  • Discord user ID and username will be removed.
  • All SCFleetFinder notifications through Discord will be disabled.
  • If you originally set up your account through Discord and did not create a password, you will need to use the 'forgot password' option on the login screen to set one to log in again.
  • You can re-link later if you want to.
If you would prefer to disable or limit Discord notifications, you can do this by changing your notification preferences on the "Notifications" tab of the Profile page.
