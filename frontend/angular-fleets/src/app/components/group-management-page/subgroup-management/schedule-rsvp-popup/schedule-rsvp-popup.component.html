This system includes two different approaches to scheduling RSVPs to provide simplicity in one form, and granularity for complex events in the other. These two RSVP scheduling methods cannot be mixed.

Global RSVPs are sent to all members on the 'Active Roster' regardless of whether they have been assigned to a position, and regardless of which subgroup a position they have been assigned to is nested in. Global RSVPs are the much more straight forward approach. If you set a Global RSVP, every member in your 'Active Roster' will be sent the same event information (excepting member position assignments) at the same time.

Use Global RSVPs if any of these scenarios are true:
  • You have a single event start time and would like to send RSVPs to all members at the same time, with the same event schedule and comms channel information
  • You are not using the group composition features of this tool to create subgroups and assign members to roles
  • You don't want to deal with thinking through RSVPs for multiple layers of subgroups or anticipating different start times and it is sufficient to send everyone in the group the same event information

Subgroup-Level RSVPs are sent to members of the specified subgroup and the subgroups nested within it IF those subgroups do not have an RSVP scheduled with greater specificity. Greater specificity meaning: an RSVP directly assigned to that subgroup or an RSVP inherited from a closer ancestor subgroup.

Subgroup-Level RSVPs can be straightforward as well if you arrange the subgroups with logical separation and don't try to add unnecessary complexity regarding different start times.

Use Subgroup-Level RSVPs if:
  • Your group composition includes multiple subgroups AND the members of these subgroups should join the event(s) at different times
  • You can at least approximately anticipate when these different start times will be
Or:
  • You want to use different RSVPs to send different comms channel information to different subgroups
  • You want to use different RSVPs to send different messages with the RSVPs to different subgroups
